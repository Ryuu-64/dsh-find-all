# dsh-find-all

DSH Desktop 的 **⌘F / Ctrl+F 会话查找**插件。默认从当前会话的已保存历史搜索，只在跳转到结果时让原聊天加载对应位置。

## 功能

- **完整会话**：以开始读取时的事件序号为固定截点，分页验证从序号 0 到截点连续无缺页。历史读取、文字扫描和结果展示上限分别计数；异常或无法识别的文字会明确提示未完成。
- **已加载内容**：保留原有页面文字查找，不再读取更多历史。缺少完整历史接口的旧宿主仍可使用此模式。
- **按需定位**：普通正文、Markdown、思考与已支持的工具正文在原聊天中定位。展开宿主原有折叠控件，并验证消息、正文块和命中文字；不能精确对应时显示原因和命中片段。
- **固定范围**：结果截止到已显示的事件序号。用刷新按钮重新读取之后保存的内容；实时未保存尾部的匹配数量单列，不混入历史总数。
- **当前会话缓存**：换关键词重新扫描内存文字，不重新下载全部历史。缓存仅属于当前会话；切换会话或禁用插件即清除，不写入数据库或本地存储。
- **可停止**：点击正在读取或扫描的状态文字停止任务。关闭、切换范围或会话会取消旧任务；旧回调不能继续高亮或跳转。
- **熟悉的操作**：Enter / Shift+Enter 上下一个；⌘G（Ctrl+G）/ F3，加 Shift 反向；Esc 关闭。查找栏可拖动或用移动按钮调整，保留返回搜索前阅读位置的功能。

仅展示前 5000 个结果，文字扫描继续完成，已读完不等于已搜完。搜索按原始 UTF-16 文字作 Unicode 大小写不敏感的字面匹配，不做空白或 Unicode 归一化，不跨独立正文块。

## 安装

先按 **DSH 运行时版本**选择安装入口；它不一定等于 Desktop 产品版本。

**运行时 0.2.0-rc.2**：用 Desktop 自带的插件命令安装：

```sh
dsh plugin --profile desktop add @ryuu-64/dsh-find-all
```

**运行时 0.2.0-rc.1 / 0.1.7-rc.2**：这两个官方安装包没有上述新版 CLI 入口，通用 `dsh plugin --profile desktop` 也会拒绝操作。请在 Desktop 中打开「插件 / Plugins」→「添加插件 / Add plugin」，填入 `@ryuu-64/dsh-find-all`，点击「安装 / Install」，完成后点击「立即启用 / Enable now」。不要用版本豁免绕过安装错误。

安装后**完整重启一次 DSH Desktop**，再检查插件是否正常加载。

装完按 **⌘F / Ctrl+F**，右上角出现查找栏就算装好了。

### 和 dsh-find-bar 只能留一个

`dsh-find-bar` 和本插件**都会抢 Ctrl+F**，两个同时装会互相顶掉。如果你之前装过它，先卸掉。运行时 0.2.0-rc.2 可用：

```sh
dsh plugin --profile desktop remove dsh-find-bar
```

运行时 0.2.0-rc.1 / 0.1.7-rc.2 请在「插件 / Plugins」中找到 `dsh-find-bar` 并选择「卸载 / Uninstall」。

## 使用

| 操作 | 按键 |
| --- | --- |
| 打开查找栏 | `⌘F` / `Ctrl+F` |
| 下一个 / 上一个命中 | `Enter` / `Shift+Enter` |
| 下一个 / 上一个命中（另一套） | `⌘G`（`Ctrl+G`）/ `F3`，加 `Shift` 反向 |
| 切换范围 `完整会话` ↔ `已加载内容` | 点查找栏上的胶囊按钮 |
| 停止读取或扫描 | 点正在忙碌的状态文字 |
| 更新已保存历史截点 | 点刷新按钮 |
| 关闭并清除高亮 | `Esc` |

文字匹配在客户端完成，历史通过当前连接的 DSH Host 会话接口读取。插件不修改会话，不把文字发送到其他服务。Markdown 投影使用宿主公开渲染器生成不挂载的惰性模板，不为搜索加载图片。

## 范围与限制

- 完整历史路径以 DSH 0.2.0-rc.2 官方协议为基准；历史版本保留已加载模式，不沿用旧版验收结果宣称新路径已全部验证。
- 搜索已保存的人类正文、助手正文和思考、工具调用及结果文字，以及原聊天实际显示的任务触发与工具声明文字。折叠正文会在跳转时展开；宿主显示上限之外仍保存的文字会明确标为不能精确定位。正常中断后保存的助手正文仍按原消息定位。
- RC2 原 Chat 不展示的系统提示与普通后台上下文不属于聊天文字搜索范围，不抽取其配置或后台字段。
- 图片只搜索作者保存的图片描述（alt），与普通正文分块。不会搜索图片内部文字、做 OCR、读取附件内部或把资源地址当正文。图片描述没有实际文字节点时不生成高亮。
- 工具和上下文按正式字段与渲染规则提取；自定义或未知的必要文字结构无法确认覆盖时提示未完成。宿主显示上限之外仍保存的文字可搜索，但不能承诺原聊天能显示该位置。
- 关闭会取消插件订阅与后续动作；已经交给宿主的按需加载可能仍会结束，插件不会因此继续旧导航。
- 工具原结果若在保存时已经截断，会单独说明。插件仍搜索已保存的文字，未保存的工具输出不在搜索范围，也不代表历史分页有缺页。
- 5000 是结果展示上限，不是历史页数上限，也不是假定的总命中数。完成状态只适用于当前截点。

## 卸载 / 回退

运行时 0.2.0-rc.2 可用：

```sh
dsh plugin --profile desktop remove @ryuu-64/dsh-find-all   # 卸载
dsh plugin --profile desktop add dsh-find-bar               # 想换回上游那个插件
```

运行时 0.2.0-rc.1 / 0.1.7-rc.2 请在「插件 / Plugins」中卸载本插件；需要回退时，再通过「添加插件 / Add plugin」安装 `dsh-find-bar`。
